# textdrift

A generative typography instrument. Type words. Live Singapore weather animates each letter as a drifting particle in a pastel sky.

**Visual Style:** Light — Breeze (pastel sky blue, soft blue/lavender/coral temperature gradient)

**Data Source:** Open-Meteo Singapore weather API (temperature, wind speed, wind direction)

**How it works:**
- Type any text in the control panel — each letter becomes a drifting particle
- Singapore weather data drives the visuals: temperature controls letter color (cool blue to warm coral), wind speed/direction controls drift intensity and angle
- Adjust sliders for font size, wind multiplier, particle spread, and color mood
- Tap any letter to see its weather-driven properties in a detail panel
- The pastel sky background features subtle cloud wisps for atmospheric depth
